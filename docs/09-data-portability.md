# Data portability

MindRepo exports only the current authenticated user's knowledge. JSON export is versioned (`mindrepo`, version 2), includes Categories, Concept aggregates, sections, sources, contexts, freshness, ReviewCard content/state/history, relations, favorites, and attachment metadata, but never passwords, sessions, cookies, sync receipts, server secrets, revision snapshots, or attachment binary data. The importer accepts v1 and v2. Markdown export is a ZIP of readable files with language-labelled code fences, Mermaid fences, and each owned attachment copied into a sanitized adjacent attachment directory.

`/settings/data/` validates an uploaded MindRepo JSON export before any write. Preview is dry-run only. Import uses owner-local identifiers to rebuild category and concept relationships in one transaction. Duplicate titles can be skipped or imported as clearly named copies; imports always belong to the signed-in user and are normal sync-visible Concept changes.

JSON import does not recreate attachment files: attachment metadata is informational. Revision snapshots are intentionally not a normal portability payload. Retain the Markdown ZIP or a server backup when attachment binaries or revision history matter. The current upload ceiling is 2 MiB / 2,000 Concepts. JSON export is portable data, not a complete operational database backup. Unsynced browser-only changes are not included.
