# Product overview

MindRepo is a private developer knowledge system. Its three product outcomes are fast discovery, fast recall, and continuous review.

Each concept is read at the depth needed in the moment: a quick definition for a 10–30 second refresh, a simple explanation for orientation, and a deep dive for study. Code examples, mistakes, aliases, tags, relations, and review state support that workflow.

The product is a responsive, mobile-first web application and future PWA. It supports Persian RTL content, English technical terms, and LTR code. A user owns their knowledge and can use the same account and database across devices.

## Product boundaries

- Personal knowledge and learning come before publishing features.
- Content retrieval and review flows come before analytics and social features.
- The online application is the source of truth. Offline reading is additive and follows a stable online product.
- MindRepo is a modular Django monolith, not a microservice system or separate SPA.
