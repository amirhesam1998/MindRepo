Field Guide راهنمای فیلدها

راهنمای کوتاه برای زمانی که دوباره به این مفهوم برمی‌گردید.

A compact reminder for when you return to this concept later.

Organization / سازمان‌دهی
دسته‌بندی، دشواری، برچسب و علاقه‌مندی برای پیدا کردن مفهوم هستند.
Category, difficulty, tags, and Favorites organize discovery.
Explanations / توضیحات
Simple Explanation برای مرور یک‌دقیقه‌ای و Deep Dive برای جزئیات فنی است.
Use Simple Explanation for a one-minute refresh and Deep Dive for technical detail.
Aliases / نام‌های جایگزین
نام، مخفف یا عبارتی که با آن مفهوم را به یاد می‌آورید؛ در جستجو هم استفاده می‌شود.
Alternative names or abbreviations are also searchable.
Attachments / فایل‌های ضمیمه
فایل خصوصی واقعی را نگه می‌دارد؛ با Source که فقط لینک یا مشخصات منبع است تفاوت دارد.
Stores the actual private file, unlike a Source which records provenance or a link.
Code examples / نمونه‌های کد
برای هر مثال عنوان، زبان، کد و توضیح بنویسید؛ کد اجرا نمی‌شود.
Each example has a title, language, code, and explanation; MindRepo never executes it.
Common mistakes / اشتباه‌های رایج
اشتباه، پیامد آن و روش درست یا Best Practice جایگزین را ثبت کنید.
Record the mistake, its consequence, and the correct approach or better practice.
Related concepts / مفاهیم مرتبط
مفاهیم را با Related، Prerequisite، Extends، Contrasts یا Example of به هم وصل کنید.
Connect concepts as Related, Prerequisite, Extends, Contrasts, or Example of.
Knowledge freshness / به‌روز بودن دانش
اعتبار محتوا برای نسخه‌های فعلی را ثبت می‌کند؛ میزان تسلط شما نیست.
Tracks whether content is current for modern versions; it is not mastery.
Technology context / زمینه تکنولوژی
نام فناوری، نسخه و محدوده اعتبار این اطلاعات را بنویسید؛ مانند .NET 8 یا EF Core 8.
Record the technology, version, and applicability, such as .NET 8 or EF Core 8.
Custom sections / بخش‌های سفارشی
برای موضوعات بزرگ بخش‌هایی مانند Key Takeaways، Note، Warning، Comparison یا Diagram بسازید.
Split large topics into Key Takeaways, Note, Warning, Comparison, or Diagram sections.
Sources / منابع
نوع، عنوان، URL، نویسنده، نسخه و یادداشت منبع را ثبت کنید؛ MindRepo آن را Fetch نمی‌کند.
Record source type, title, URL, author, version, and notes; MindRepo does not fetch it.
Review Cards / کارت‌های مرور
هر کارت زمان‌بندی و تاریخچه مستقل دارد؛ Archive آن را حذف نمی‌کند.
Each card has an independent schedule and history; Archive does not delete it.
Sources and attachments / منابع و فایل‌های ضمیمه
منبع لینک یا مشخصات است؛ فایل ضمیمه خود فایل خصوصی را نگه می‌دارد.
A Source records provenance; an Attachment stores the private file itself.
